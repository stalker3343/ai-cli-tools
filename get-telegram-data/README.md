# get-telegram-data

Небольшой Node.js CLI-проект для выгрузки сообщений из Telegram-чатов, каналов и форумных тем через пользовательский аккаунт Telegram.

Проект полезен, когда нужно забрать историю сообщений из чата, сохранить ее в `JSON` или `Markdown`, а потом анализировать, искать по тексту, отдавать в LLM, архивировать или переносить в другой инструмент.

## Что умеет

- Авторизоваться в Telegram через GramJS (`telegram` npm-пакет).
- Искать доступный аккаунту чат по названию, `@username`, id или приватной ссылке вида `https://t.me/c/...`.
- Выгружать сообщения всего чата.
- Выгружать сообщения конкретной форумной темы.
- Показывать список тем в Telegram-форуме.
- Ограничивать выгрузку по количеству сообщений.
- Фильтровать сообщения по датам.
- Сохранять результат в `JSON` или `Markdown`.

Важно: это не Telegram-бот. Скрипт работает от имени обычного Telegram-аккаунта, поэтому видит только те чаты и каналы, к которым у этого аккаунта уже есть доступ.

## Установка

Нужен Node.js 18+.

```bash
npm install
```

## Настройка Telegram API

1. Откройте https://my.telegram.org.
2. Войдите под своим Telegram-аккаунтом.
3. Создайте приложение в разделе API development tools.
4. Скопируйте `api_id` и `api_hash`.
5. Скопируйте пример конфига:

```bash
copy config.example.js config.js
```

На macOS/Linux:

```bash
cp config.example.js config.js
```

6. Заполните `config.js`:

```js
const config = {
  api_id: 123456,
  api_hash: "your_api_hash",
  phone: "+79990000000",
  password: "", // пароль 2FA, если включен
  session: "", // строка сессии Telegram, можно оставить пустой при первом входе
};

module.exports = config;
```

Не публикуйте `config.js`, строку сессии и любые файлы с личными экспортами. В них могут быть доступы и приватные сообщения.

## Авторизация

При первом запуске скрипт подключится к Telegram и попросит код подтверждения, который придет в Telegram. Если включена двухфакторная защита, также понадобится пароль 2FA.

После успешного входа в консоль будет выведена строка сессии. Ее можно сохранить в `config.js` в поле `session`:

```js
session: "сюда_строку_сессии"
```

Если строка сессии уже сохранена, повторно вводить код обычно не нужно.

## Основная команда

Главный скрипт:

```bash
node export-chat.js <чат> [опции]
```

Также можно запускать через npm:

```bash
npm run export-chat -- <чат> [опции]
```

`<чат>` может быть:

- частью названия чата;
- `@username` публичного канала или группы;
- id чата;
- приватной ссылкой вида `https://t.me/c/123456789/123`.

## Примеры

Выгрузить все доступные сообщения чата в JSON:

```bash
node export-chat.js "Название чата" --out=exports/chat.json
```

Выгрузить последние 1000 сообщений:

```bash
node export-chat.js "Название чата" --limit=1000 --out=exports/chat.json
```

Сохранить сразу в Markdown:

```bash
node export-chat.js "Название чата" --format=md --out=exports/chat.md
```

Выгрузить сообщения за период:

```bash
node export-chat.js "Название чата" --since=2026-06-01 --until=2026-06-14 --out=exports/june.json
```

Показать список тем в форумном чате:

```bash
node export-chat.js "Название форума" --list-topics
```

Выгрузить конкретную тему форума:

```bash
node export-chat.js "Название форума" --topic="Название темы" --out=exports/topic.json
```

Выгрузить тему по id:

```bash
node export-chat.js "Название форума" --topic=123 --format=md --out=exports/topic.md
```

Выгрузить по приватной ссылке Telegram:

```bash
node export-chat.js "https://t.me/c/123456789/123" --format=md --out=exports/from-link.md
```

## Опции `export-chat.js`

| Опция | Описание |
| --- | --- |
| `--chat=<значение>` | Альтернатива позиционному аргументу `<чат>`. |
| `--topic=<тема или id>` | Выгрузить только указанную тему форума. |
| `--list-topics` | Показать темы форума и завершить работу. |
| `--limit=<число>` | Максимальное количество сообщений. `0` означает без явного лимита. |
| `--since=YYYY-MM-DD` | Брать сообщения начиная с этой даты. |
| `--until=YYYY-MM-DD` | Брать сообщения до конца этой даты. |
| `--format=json\|md` | Формат результата. Если не указан, определяется по расширению `--out`. |
| `--out=<путь>` | Куда сохранить результат. По умолчанию файл создается в папке `exports/`. |

## Формат результата

В `JSON` сохраняется массив сообщений:

```json
[
  {
    "id": 123,
    "date": "2026-06-14T10:00:00.000Z",
    "senderId": "123456789",
    "replyToTopId": 1,
    "replyToMsgId": 122,
    "message": "Текст сообщения"
  }
]
```

В `Markdown` сохраняется только текст сообщений, разделенный блоками:

```md
Первое сообщение

---

Второе сообщение
```

## Дополнительные скрипты

- `json-to-md.js` - конвертирует JSON-экспорт в Markdown.
- `json-to-text.js` - вытаскивает поле `message` из `mess.json` в `messages.txt`.
- `index.js` - старый пример ручной выгрузки через заранее заданный `inputPeer`.
- `parser.js` - экспериментальный скрипт для обработки `mess.json`.

Для обычного использования почти всегда нужен только `export-chat.js`.

## Частые проблемы

### `Chat not found`

Скрипт не нашел чат среди доступных диалогов аккаунта. Проверьте, что аккаунт состоит в нужном чате, и попробуйте указать более точное название, `@username`, id или приватную ссылку.

### Найдено несколько чатов

Запрос слишком общий. Укажите более точное название или id.

### Тема не найдена

Сначала выполните:

```bash
node export-chat.js "Название форума" --list-topics
```

Затем используйте точное название темы или ее id из вывода.

### Нужно переавторизоваться

Очистите или замените поле `session` в `config.js`, затем снова запустите экспорт и пройдите вход.
