# crear-tg-log

Короткий Python-скрипт для очистки JSON-экспорта Telegram-чата. Проект берет стандартный `result.json` из Telegram Desktop, оставляет id, дату, автора, текст сообщений и ссылки, а медиа, реакции и лишние служебные поля убирает.

## Зачем нужен

Telegram-экспорт часто получается большим и шумным: внутри есть реакции, сведения о файлах, стикерах, фото, размерах медиа и другие поля, которые мешают анализу. `slim_tg_export.py` делает облегченную JSON-версию, которую удобнее читать, архивировать или отдавать в LLM/инструменты анализа.

## Что лежит в папке

- `slim_tg_export.py` - основной скрипт очистки.
- `ChatExport_2026-04-19/result.json` - исходный пример экспорта Telegram.
- `ChatExport_2026-04-19/result_slim.json` - пример уже уменьшенного результата.
- `ChatExport_2026-04-19/stickers` и `video_files` - медиа из экспорта, которые скрипт не переносит в итоговый JSON.

## Требования

Нужен только Python 3.10+ или близкая современная версия Python 3. Внешние зависимости не используются.

Проверить Python:

```powershell
python --version
```

## Быстрый запуск

Из папки проекта:

```powershell
python slim_tg_export.py ChatExport_2026-04-19\result.json
```

По умолчанию рядом с исходным файлом будет создан:

```text
ChatExport_2026-04-19\result.slim.json
```

## Запуск с явным выходным файлом

```powershell
python slim_tg_export.py ChatExport_2026-04-19\result.json -o ChatExport_2026-04-19\result_slim.json
```

## Полезные опции

- `--drop-empty` - удалить сообщения без текста после очистки. Включено по умолчанию.
- `--keep-empty` - оставить сообщения без текста после очистки.
- `--indent 0` - записать компактный JSON без форматирования.

Пример:

```powershell
python slim_tg_export.py ChatExport_2026-04-19\result.json --indent 2
```

## Что сохраняется в результате

Скрипт переносит только основные поля:

- `id`
- `date`
- `from`
- `text`
- `links`, если в сообщении были текстовые ссылки

Поле `text` нормализуется: если Telegram хранит текст как список фрагментов, скрипт собирает его обратно в обычную строку.

## Приватность

Экспорты Telegram могут содержать личные сообщения, имена пользователей и ссылки. Перед публикацией результата проверьте, что в итоговом JSON нет приватных данных.
